# 언어의 마술사 · Language Magician

언어가 부족한 외국인이 **자기가 쓰던 메신저(카카오톡·위챗·LINE·WhatsApp·인스타 DM·Telegram·Zalo·Messenger)** 에서 외국 친구와 막힘없이 대화하도록 돕는 대화 도우미 웹앱입니다.
내 언어로 쓰면 상대 언어로 바꿔 주고, 받은 말은 내 언어로 풀어 줍니다. 상대의 성향과 지금 상황을 파악하고, 여러 사람과의 관계를 기념일·약속·지난 대화까지 관리합니다.

- 기획: Claude + ChatGPT 공동 검토
- 디자인: ChatGPT 시안(HTML/CSS 15개 화면) 기반
- 구현·배포: Claude

## 화면 (사용자 앱 · 표시 언어 한/中/日/Việt/EN 자동 전환)

| 화면 | 기능 |
| --- | --- |
| 온보딩 | 표시 언어 선택, 게스트 바로 사용 / 닉네임 가입(실명 없음), 운영 모니터링 필수 동의 |
| 홈 | 상대 먼저 선택 → 받은 말 번역 / 내 말 → 상대 언어 복사, 오늘 챙길 것(약속·기념일·답장 안 한 사람), 연락처 |
| 대화 도우미 | 붙여넣기·스크린샷(OCR), 번역·뉘앙스·현재 상황(사실/추정 구분), 지난 대화 기억(관련 대화·놓친 질문·지난 약속·시간 충돌·중복 질문), 약속 자동 추출→알림, 답장 방향 3가지, 직접 쓰기+말투, 위험(금전 요구·외부 유도) 경고·신고 |
| 연락처 | 앱/닉네임·색상 구분, 만난 날 D+N, 생일, 다음 약속, 할 일, 성향 분석(말투·답장 속도·활동 시간·분위기·주제·대화 깊이), 최근 대화, 노트 |
| 관계 코칭 | 연인(알아가기→친해지기→호감→고백→연인)·친구·비즈니스 단계별 다음 행동·피할 말·예문 |
| 일정 | 약속 추가·완료·캘린더(.ics) 내보내기, 휴대폰 알림 |
| 기념일 | 생일(음력 지원), 만난 날 100·200·300·500·1000일·주년, 상대 나라 명절 자동 |

## 관리자 (`#/admin`, 한국어)

운영 현황 · 회원 CRM(회원별 상대 수, 상대별 진행 기간·단절 일수·관계 단계·대화 깊이·분위기·위험, 앱 분포) · 전체 대화 모니터링(회원→상대→대화 3단, 원문·번역·AI 제안·선택 답장 비교, 열람 사유 필수) · 신고 처리 · 개선 메모 · 열람 감사로그 · 이용 차단/해제.

- 초기 PIN `0000` → 로그인 후 운영 설정에서 반드시 변경
- 서버 미연결 시: 이 기기 데이터 + 데모 회원 8명 표시

## 번역·AI

- 기본: MyMemory 무료 번역 API (키 불필요, IP당 하루 사용량 제한 있음)
- 선택: 설정에서 Claude 또는 OpenAI 키 입력 → 뉘앙스·상황·답장·코칭을 AI가 생성, 스크린샷 인식도 AI 사용
- 정식 서비스에서는 키를 서버(Edge Function)로 옮겨야 합니다

## 모든 회원 대화를 서버에 모으기 (Supabase, 무료)

1. supabase.com 에서 프로젝트 생성
2. SQL Editor 에서 `supabase/schema.sql` 실행
3. `js/config.js` 에 URL·anon key 입력 후 배포

정식 출시 전 할 일: Supabase Auth(익명 로그인) 도입, 회원은 자기 행만 쓰기·관리자 역할만 전체 조회로 RLS 정책 축소.
